Server certificate

This server uses its own certificate for its encrypted connections. Windows does not know it yet, so the game refuses to connect until you trust it once.

Installing adds to your Windows user's trusted certificates. No administrator rights are needed. Windows asks you to confirm; choose Yes.

To remove it later: run certmgr.msc, open Trusted Root Certification Authorities, Certificates, and delete it.
